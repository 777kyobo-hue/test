# 7초 카드뉴스 메이커

GPT로 정리한 뉴스나 내용을 붙여 넣으면, 카드 한 장마다 7초짜리 인스타그램용 MP4 영상으로 만들어 주는 웹 도구예요.
설치할 것 없이 `index.html` 파일 하나로 브라우저에서 돌아가요.

## 사용 방법

1. `index.html`을 Chrome, Edge, Safari 최신 버전으로 열어요.
2. **GPT 프롬프트 복사**를 눌러 GPT에 붙여 넣고, `[내용]` 자리에 기사나 주제를 넣어요.
3. GPT 답변을 왼쪽 칸에 붙여 넣어요.
   - 카드는 `---` 줄로 나눠요.
   - 각 카드의 첫 줄은 제목, 나머지 줄은 본문이에요.
   - `출처:`로 시작하는 줄은 카드 하단에 작게 들어가요.
   - 첫 카드는 표지가 돼요.
4. 비율(피드 4:5, 릴스 9:16, 1:1), 테마, 계정 이름을 고르고 저장해요.

## 기능

- 카드당 길이: 기본 7초 (3~30초)
- 테마 6가지, 제목 글꼴 2가지, 배경 사진 (선택)
- 카드마다 뉴스 영상 파일의 원하는 구간 넣기 (위쪽 틀 / 전체 배경)
- 저장 방식
  - 선택한 카드 MP4
  - 모든 카드 MP4 (ZIP)
  - 한 편으로 이어 붙인 MP4
  - PNG 이미지 (ZIP)
- 영상: 1080px 너비, 30fps, H.264 MP4, 소리 없음

## GitHub Pages로 바로 쓰기

저장소 **Settings → Pages**에서 브랜치를 `main`, 폴더를 `/ (root)`로 정하면
`https://<계정>.github.io/<저장소>/cardnews-maker/` 주소로 열 수 있어요.

## 사용한 라이브러리

- [mp4-muxer](https://github.com/Vanilagy/mp4-muxer) 5.1.3: MP4 파일 만들기
- [JSZip](https://stuk.github.io/jszip/) 3.10.1: ZIP 묶기
- Google Fonts: Black Han Sans, Noto Sans KR

## 참고

- 유튜브 링크는 넣을 수 없어요. 영상 파일을 직접 골라 넣어야 해요.
- 방송사 뉴스 영상에는 저작권이 있으니, 직접 찍었거나 사용이 허락된 영상을 쓰세요.
